# IdolOS β

A static prototype for an idol-focused AI manager landing page. It includes the marketing hero, pricing cards, and three interactive tool flows:

- **AI Manager**: generates SNS copy, TikTok ideas, and a short MC script.
- **AI Academy**: organizes activity concerns into next steps and reusable copy.
- **Performance Coach**: turns live-performance reflections into practical improvement points.

## Run locally

```bash
npm start
```

Then open <http://localhost:4173>.

## Checks

```bash
npm run check
```
